## 优先推进

- **输入可靠性**：扩展应用兼容性、焦点切换、选区与光标、快速输入和中英文切换的可复现场景。
- **呈现一致性**：验证多显示器、不同 DPI、横纵布局、主题缩放与皮肤导入兼容性。
- **安装生命周期**：在隔离 Windows 11 环境验证安装、升级、卸载、已加载 DLL 清理、注销与重启收敛。
- **发布可追溯性**：在验收完成后形成清晰的发布说明、下载校验、签名与版本管理流程。

## 实验方向

上下文候选排序与小模型的目标是探索更合适的候选，但目前没有足够公开证据证明效果提升。进入常规路径前需要：

1. 建立独立且足够规模的基线与评测集，区分合成诊断样例和实际评测。
2. 确认数据来源、许可、隐私与本地处理边界。
3. 同时评估输入准确性、延迟、资源开销和回退行为。
4. 发布可复核的结果与局限，再讨论产品接入。

当前的[合成样例](../tests/data/contextual-ranking-pilot.README.md)仅用于开发诊断，不用于宣称最终输入效果或模型性能。

## 如何推动项目

最有帮助的贡献是最小复现、可分享的合成用例、应用兼容性报告和针对具体问题的小修复。提出新功能时，请说明输入场景、预期行为以及现有方式的不足；参见[贡献指南](../CONTRIBUTING.md)。
